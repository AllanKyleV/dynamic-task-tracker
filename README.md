# Dynamic Task Tracker

A simple and interactive task tracker built with HTML, CSS, and JavaScript. This mini-project allows users to manage their daily tasks by adding, marking as complete, and deleting them. It’s a great practice project for learning DOM manipulation and event handling in JavaScript.

## Features

- Add new tasks
- Mark tasks as complete/incomplete
- Delete tasks
- Responsive and user-friendly UI
- (Coming soon) Persistent storage using `localStorage`

## Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)
